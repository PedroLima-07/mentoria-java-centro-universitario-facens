```markdown
# 🏋️‍♂️ Exercícios: Dominando Arrays (Vetores)

Chegou a hora de praticar! Lembrar que o índice começa no `0` e que usamos colchetes `[ ]` é o maior desafio no começo. Crie os arquivos `.java` no seu VS Code e resolva os problemas abaixo.

### 📝 Exercício 1: A Chamada da Turma

**Arquivo:** `Chamada.java`

**Cenário:** Você precisa listar o nome dos alunos que chegaram na sala de aula.

**O que você deve fazer:**

1. Crie um array de `String` já inicializado com 5 nomes de sua escolha (ex: `{"Pedro", "Ana", ...}`).
2. Crie um laço `for` clássico para percorrer esse array.
3. Imprima no console uma mensagem de boas-vindas para cada aluno. (Ex: "Bem-vindo(a), Pedro!").

---

### 📊 Exercício 2: Calculadora de Boletim

**Arquivo:** `Boletim.java`

**Cenário:** Um professor quer automatizar o cálculo da média de um aluno que fez 4 provas durante o ano.

**O que você deve fazer:**

1. Crie um array de `double` chamado `notas` com os valores: `8.5`, `7.0`, `9.0` e `5.5`.
2. Crie uma variável `double soma = 0;` antes do laço para acumular o total.
3. Use um laço `for` para percorrer o array e ir somando cada nota na variável `soma`.
4. Após o laço, calcule a média dividindo a soma pela quantidade de notas (dica: use `notas.length`).
5. Imprima a soma total e a média final do aluno.

---

### 🚀 Desafio: Encontrando o Maior Número

**Arquivo:** `MaiorNumero.java`

**Cenário:** Você tem uma lista de pontuações de um jogo e precisa descobrir qual foi o recorde (o maior número).

**O que você deve fazer:**

1. Crie um array de `int` chamado `pontuacoes` com os valores: `45`, `89`, `32`, `104`, `77`.
2. Crie uma variável chamada `maior` e diga que o valor inicial dela é igual à primeira gaveta do array (ex: `int maior = pontuacoes[0];`).
3. Crie um laço `for` para percorrer o array.
4. Dentro do laço, faça um `if`: se a pontuação atual (`pontuacoes[i]`) for maior que a variável `maior`, então a variável `maior` recebe esse novo valor.
5. No final, imprima o recorde encontrado!
```
