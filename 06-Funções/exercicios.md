# 🏋️‍♂️ Exercícios: Funções em Java

Agora chegou a hora de praticar funções!

O objetivo desta lista é aprender:
- como criar funções,
- como chamar funções,
- usar parâmetros,
- e devolver valores com `return`.

Crie os arquivos `.java` no VS Code e resolva os exercícios abaixo.

---

# 📝 Exercício 1: Mensagem de Boas-vindas

**Arquivo:** `BoasVindas.java`

## Cenário

Você foi contratado para criar o início de um sistema escolar.

Toda vez que o programa iniciar, ele deve mostrar uma mensagem de boas-vindas usando uma função.

## O que você deve fazer:

1. Crie uma função chamada `mostrarMensagem`.
2. A função deve imprimir:
   `"Bem-vindo ao sistema escolar!"`
3. No `main`, chame essa função.

# 📊 Exercício 2: Calculadora de Soma

**Arquivo:** `Calculadora.java`

## Cenário

Você precisa criar uma função que some dois números.

## O que você deve fazer:

1. Crie uma função chamada `somar`.
2. Ela deve receber dois números inteiros (`int`).
3. A função deve retornar a soma dos números.
4. No `main`, chame a função e mostre o resultado no console.

Exemplo esperado:

```java
Resultado: 15
```

# 🎓 Exercício 3: Média do Aluno

**Arquivo:** `MediaAluno.java`

## Cenário

Um professor quer automatizar o cálculo da média dos alunos.

## O que você deve fazer:

1. Crie uma função chamada `calcularMedia`.
2. Ela deve receber duas notas do tipo `double`.
3. A função deve retornar a média.
4. No `main`, mostre:
   - as notas
   - e a média final.

# 🚀 Desafio: Verificador de Número Par

**Arquivo:** `NumeroPar.java`

## Cenário

Você precisa criar um sistema que descubra se um número é par ou ímpar.

## O que você deve fazer:

1. Crie uma função chamada `verificarPar`.
2. Ela deve receber um número inteiro.
3. Dentro da função:
   - se o número for par, mostre `"Número par"`
   - senão, mostre `"Número ímpar"`
4. No `main`, chame a função passando alguns números diferentes.

Dica:
Use o operador `%`.

Exemplo:

```java
numero % 2 == 0
```
