# 🔁 Módulo 04: Estruturas de Repetição (Laços / Loops)

Imagine que o seu chefe pediu para você fazer um programa que imprima a frase "Bom dia!" na tela 100 vezes. Você copiaria e colaria o comando `System.out.println` 100 vezes? Claro que não!

É exatamente para isso que existem as **Estruturas de Repetição** (também conhecidas como Laços ou _Loops_). Elas permitem que o computador repita um bloco de código várias vezes de forma automática e muito rápida.

Para facilitar o seu estudo, dividimos este módulo em três pastas, cada uma focada em uma ferramenta de repetição diferente.

### 📁 O que você vai encontrar aqui:

- **[For (Para)](./for/)**: O laço ideal para quando você **sabe exatamente** quantas vezes o código precisa se repetir (Ex: contar de 1 a 10). É a estrutura mais organizada e usada no dia a dia.

- **[While (Enquanto)](./while/)**: O laço perfeito para quando você **não sabe** a quantidade de repetições, mas tem uma condição (Ex: continuar pedindo a senha _enquanto_ o usuário digitar a senha errada).

- **[Do While (Faça Enquanto)](./do-while/)**: O "primo" do While. A grande diferença é que ele garante que o código seja executado **pelo menos uma vez** antes de checar se deve repetir de novo (Ex: mostrar um menu na tela antes de pedir a opção do usuário).

Escolha uma das pastas acima para mergulhar na teoria e colocar a mão na massa com os exercícios. Lembre-se: entender _quando_ usar cada um deles é o segredo dos grandes programadores! 🚀
