# 🏋️‍♂️ Exercícios: Dominando o Switch Case

Agora é a sua vez de criar os seus próprios menus e seletores. Crie os arquivos `.java` no seu VS Code e mãos à obra!

---

### 📅 Exercício 1: Dias da Semana

**Arquivo:** `DiaDaSemana.java`

**Cenário:** Precisamos de um conversor que transforme um número no dia da semana correspondente.

- 1 = Domingo
- 2 = Segunda-feira
  ...
- 7 = Sábado.

**O que você deve fazer:**

1. Crie uma variável `int dia`.
2. Use o `switch` para imprimir o nome do dia correto.
3. Se o número for menor que 1 ou maior que 7, o `default` deve imprimir "Dia inválido!".

---

### 🎧 Exercício 2: Atendimento Eletrônico (URA)

**Arquivo:** `Atendimento.java`

**Cenário:** Você foi contratado para programar o robô de atendimento de uma operadora de internet. As opções são:

- 1 - Falar com o Suporte Técnico
- 2 - Pedir 2ª via do Boleto
- 3 - Alterar Plano
- 4 - Cancelar Serviço

**O que você deve fazer:**

1. Crie a variável para receber a opção do cliente.
2. Crie os `cases` imprimindo mensagens amigáveis (Ex: "Aguarde, estamos transferindo para o Suporte...").
3. Não esqueça do `default` para opções que não existem.

---

### 🚀 Desafio: A Calculadora Básica

**Arquivo:** `Calculadora.java`

**Cenário:** Vamos construir a lógica de uma calculadora que aceita o sinal da operação matemática como texto (`String`).

**O que você deve fazer:**

1. Crie duas variáveis para os números (ex: `double num1 = 10.0;` e `double num2 = 5.0;`).
2. Crie uma variável `String operacao = "+";` (teste depois com "-", "\*", "/").
3. Faça um `switch` testando a variável `operacao`.
4. Em cada `case`, faça o cálculo correto e imprima o resultado. (Exemplo no `case "+":`, imprima a soma de `num1` e `num2`).
