# 🚦 Módulo 03: Estruturas Condicionais

Até agora, nossos códigos rodavam em uma linha reta, do começo ao fim. Mas e se o programa precisar tomar uma decisão? É para isso que servem as **Estruturas Condicionais**! Elas são as "bifurcações" do nosso código.

Para facilitar o seu estudo, dividimos este módulo em duas pastas.

### 📁 O que você vai encontrar aqui:

- **[If / Else](./if-else/)**: A estrutura "Se / Senão". É a ferramenta de decisão mais poderosa e usada na programação. Perfeita para checar regras flexíveis, intervalos e condições complexas (ex: _se a nota for maior que 7 E a falta menor que 5_).
- **[Switch Case](./switch/)**: O "Interruptor". Uma estrutura mais limpa e organizada, ideal para quando temos opções fixas e exatas (ex: _digite 1 para saldo, 2 para extrato, 3 para sair_).

Escolha uma das pastas acima para mergulhar na teoria e fazer os exercícios. Bons estudos! 🚀
